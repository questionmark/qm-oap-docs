PracticeAttempts PracticeAttempt¶
Methods Supported:

  • GET – read practice attempt entities

  • DELETE – delete a practice attempt entity

Filters supported:

  • ID – primary key

The PracticeAttempts feed provides access to information about practice attempts taken by participants.

EntityType: PracticeAttempt¶

An entity representing a participant’s practice attempt.

Entity Key: ID Edm.Int32 NOT NULL¶

The numeric ID of the practice attempt.

ParticipantID Edm.Int32 NOT NULL¶

A reference to the Participant that took the practice attempt.

MonitoringTypeID Edm.Int32 NOT NULL¶

A reference to the MonitoringType associated with the practice attempt.

AppointmentID Edm.Int32¶

An optional reference to the associated Appointment.
