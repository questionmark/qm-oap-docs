QuestionQML¶

QuestionQMLs QuestionQML¶
Methods Supported:

  • GET – feed is read only

Filters supported:

  • QuestionRevisionId – part of the composite key

  • Language – part of the composite key (translation language)

EntityType: QuestionQML¶

QuestionQML entities are media-link entities containing the full XML description of the Question.

Entity Key: QuestionRevisionId Edm.Int32 NOT NULL¶

The ID of the parent QuestionRevision entity.

Entity Key: Language Edm.String NOT NULL¶

The language code for this QML translation.

CreatedDateTime Edm.DateTimeOffset NOT NULL¶

The date and time (in UTC) when this translation was created.

Author Edm.String¶

The user name of the user that created this translation.

ModifiedDateTime Edm.DateTimeOffset NOT NULL¶

The date and time (in UTC) when this translation was last modified.

Editor Edm.String¶

The user name of the user that last modified this translation.

TranslationStatus Edm.Int32¶

Status indicator for the translation.

IsDeleted Edm.Boolean NOT NULL¶

A flag indicating whether or not this QML has been deleted.

QuestionRevision QuestionRevision¶

Navigation property to the parent QuestionRevision entity.
